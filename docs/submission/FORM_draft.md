# 해커톤 제출 폼

글자 수는 공백 포함이고 각 항목 끝에 실측값을 적었다.
수치는 전부 실제 실행에서 나온 것이고, 아직 측정 중인 것은 적지 않았다.
(이 메모만 평어체이고, 아래 제출 본문은 전부 존댓말이다.)

---

## 1. 해결하고자 했던 문제 (300자 내외)

공공데이터 API를 붙이는 개발자는 "연결은 됐는데 데이터가 이상한" 상황에서 가장 오래
막힙니다. 200 OK가 오고 코드도 안 죽는데 페이지 경계에서 레코드가 새거나, 필드가 조용히
비거나, 요청한 범위와 받은 범위가 어긋납니다. 에러가 없으니 어디를 봐야 할지 단서가 없고
결국 응답을 눈으로 훑으며 며칠을 씁니다. 여기에 LLM을 붙이면 문제가 더 커집니다. 모델이
"고쳤습니다"라고 말하는 순간 그 말이 곧 결론이 되기 때문입니다. 고친 쪽이 채점까지 하는
구조에서는 틀린 수리가 통과합니다. 그래서 판정 권한을 모델에게서 완전히 뺀 API 진단
복구 도구를 만들었습니다.

## 2. 서비스 소개 및 주요 기능 (500자 내외)

api-doctor는 API 연동 코드를 받아 결함을 진단하고 고친 뒤, 그 수리가 진짜인지를 LLM
없이 검증하는 CLI 도구입니다. 원칙은 하나입니다. LLM은 어디를 볼지만 정하고, 무엇이
참인지는 LLM이 없는 코드가 정합니다. 모델이 도는 구역이 검증기와 기대값과 네트워크에
닿지 못하게 시스템을 네 구역으로 나누고, 그 경계를 CI가 AST로 검사합니다.

사용자 흐름입니다.

1. `api-doctor run <코드>`로 네트워크가 끊긴 컨테이너에서 실행합니다. 실행 전에 격리가
   실제로 작동하는지 자가검사 5종으로 증명합니다.
2. 고정 검증기가 실행, 필드, 값, 전체성을 봅니다. 원본이 이미 정상이면 모델을 한 번도
   부르지 않고 끝납니다.
3. 결함이 확인될 때만 1+4 에이전트 팀을 부릅니다.
4. 감사자는 수리자의 설명을 받지 못합니다. 런타임이 중립 봉투를 새로 조립해 관측
   증거만 넘기므로, 직접 probe를 돌려야 결론을 낼 수 있습니다.
5. 종료 게이트가 네 조건을 전부 만족할 때만 성공으로 승격합니다. 우회 경로는 없습니다.

## 3. 활용한 핵심 기술 및 AI 모델

### NVIDIA

| 항목 | 내용 |
|---|---|
| 모델 | `nvidia/nemotron-3-super-120b-a12b` (reasoning) |
| 폴백 | `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning` |
| 엔드포인트 | NVIDIA NIM, `https://integrate.api.nvidia.com/v1` (OpenAI 호환) |
| 발급 | build.nvidia.com 무료 등급 |
| 프로파일링 | NeMo Agent Toolkit 형식의 역할별 구간 리포트 |

reasoning 모델이라 추론 토큰이 `completion_tokens`에 함께 잡힙니다. 사소한 JSON 한
줄에도 출력 258토큰이 나갔습니다. 그래서 역할별 출력 상한을 따로 잡았습니다
(수리자 12288, 나머지 3072).

무료 등급의 가용성을 모델별로 8회씩 실측했습니다. 주 모델이 1/8이라 503에는 기다리지
않고 폴백 모델로 즉시 갈아타도록 했고, 적용 후 같은 조건에서 10/10이 됐습니다. 어떤
모델이 응답했는지는 호출마다 기록합니다.

### 에이전트 하네스

- deepagents 0.7.19가 기본 하네스입니다
- LangChain의 `wrap_tool_call` 미들웨어 훅에서 `task` 위임을 가로채 예산과 권한과
  중복 위임을 검사합니다
- 기본 파일시스템 백엔드가 호스트에 닿지 않는 `StateBackend`임을 확인하고
  `FilesystemMiddleware(tools=["read_file"])`로 쓰기 도구를 제거했습니다
- 자동 요약 미들웨어는 껐습니다. main의 모델 예산을 몰래 먹고 있었습니다

### 격리 실행

- Docker `--network none --read-only --cap-drop ALL --security-opt no-new-privileges
  --user 65534:65534 --pids-limit 32 --memory 512m --cpus 1 --tmpfs /tmp`
- 후보 코드와 브로커 사이는 JSONL IPC입니다. API 키는 `{KEY}` 자리표시자로만 전달되어
  후보 코드가 실제 키를 읽을 수 없습니다

### 그 외

Python 3.12, uv, Typer, Rich, Pydantic, httpx, pytest

### 실측 (2026-09-28)

- 격리 경계 자가검사 5/5 차단 (환경변수 카나리아 포함)
- 결함 탐지 평가 18/18, 거짓 성공 0건
- 테스트 181개 통과, 구역 간 import 경계는 CI가 AST로 강제
